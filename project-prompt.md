# Pavan Graphics - 3D Antigravity Website

## Design Concept & Philosophy
The website for "Pavan Graphics" is built on the concept of an "Antigravity Workspace." Just as creativity has no bounds, the digital environment where Pavan's services are showcased floats freely in space. The aesthetic blends deep space themes (blacks, dark purples) with vibrant neon cyber-accents (pink, cyan) to create a striking contrast that immediately grabs the visitor's attention.

The use of 3D geometric shapes floating in the background symbolizes the raw building blocks of design (shape, form, color) suspended in creative thought.

## Technical Architecture
- **Framework:** React (Vite)
- **3D Graphics:** Three.js via `@react-three/fiber` and `@react-three/drei`
- **Animations:** Framer Motion for scroll-triggered reveals, layout transitions, and interactive hover states.
- **Styling:** Vanilla CSS with custom CSS variables for a consistent and highly optimized styling approach. Glassmorphism techniques are used for UI panels.
- **Icons:** `lucide-react` for scalable, consistent iconography.
